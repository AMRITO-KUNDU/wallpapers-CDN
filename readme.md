# Wallpaper CDN

A small, free wallpaper catalog served straight from GitHub.
Drop images into folders, push, and get a ready-to-use `images.json`.
No backend, no database, no API key.

## Quick start

```
https://raw.githubusercontent.com/AMRITO-KUNDU/wallpapers-CDN/main/images.json
```

```js
const catalog = await fetch(
  "https://raw.githubusercontent.com/AMRITO-KUNDU/wallpapers-CDN/main/images.json"
).then(r => r.json());

const abstract = catalog.filter(w => w.category === "abstract");
```

Works from Flutter, React Native, web or a shell script — it is just JSON over HTTPS.

### Image URLs

Images are served from jsDelivr, pinned to the commit that last touched each
file:

```
https://cdn.jsdelivr.net/gh/AMRITO-KUNDU/wallpapers-CDN@<sha>/wallpapers/...
```

The pin is what makes it work. jsDelivr refuses files it has not cached once a
repo passes its 50 MB package limit, and it applies that check when resolving a
branch such as `@main` — but not a commit. Pinning skips the check and keeps the
edge cache, and because the ref only moves when the file changes, the URL stays
stable.

jsDelivr still refuses a small number of files on this repo, so every record
carries a `fallback` on `raw.githubusercontent.com`, which has no size limit:

```json
"fallback": { "url": "...", "thumbnail": "..." }
```

Use `url` / `thumbnail`, and retry `fallback` if the request fails.

## Structure

```text
.
├── wallpapers/<Category>/<file>.webp    the images
├── thumbnails/<Category>/<file>.webp    generated previews, 480px wide
├── images.json                          generated index
├── tags-index.json                      generated tag counts
├── scripts/                             the three build scripts
└── .github/workflows/generate-image-json.yml
```

Each folder inside `wallpapers/` is a category.

## JSON format

A flat array, one object per wallpaper:

```json
{
  "id": "abstract-candy-orb-01",
  "name": "Candy Orb 01",
  "category": "abstract",
  "url": "https://raw.githubusercontent.com/AMRITO-KUNDU/wallpapers-CDN/main/wallpapers/Abstract/candy-orb-01.webp",
  "thumbnail": "https://raw.githubusercontent.com/AMRITO-KUNDU/wallpapers-CDN/main/thumbnails/Abstract/candy-orb-01.webp",
  "width": 1440,
  "height": 3120,
  "orientation": "portrait",
  "format": "webp",
  "credit": {
    "author": "wallpapers-CDN (generated)",
    "license": "MIT",
    "source": "Generated by scripts/generate-procedural-wallpapers.js",
    "url": "https://github.com/AMRITO-KUNDU/wallpapers-CDN"
  },
  "tags": [
    "abstract",
    "orb",
    "glow",
    "sphere",
    "candy",
    "minimal",
    "dark",
    "phone"
  ]
}
```

| Field | Description |
|---|---|
| `id` | Stable id, `category-file-slug` |
| `name` | Display name |
| `category` | Lowercase category slug |
| `url` | Full-size image |
| `thumbnail` | 480px WebP preview |
| `width` / `height` | Pixels |
| `orientation` | `portrait`, `landscape` or `square` |
| `format` | `webp`, `jpg`, `png` or `gif` |
| `tags` | Search tags, always includes the category |
| `credit` | Optional author, license, source, url |

## Tags

Every record carries a `tags` array with its category first. To add your own,
put a `<file>.json` next to the image:

```json
{ "title": "Dusk Mesh 01", "tags": "gradient, mesh, dusk, dark" }
```

`tags-index.json` lists every tag with how many wallpapers use it, most-used
first, so a client can build a filter bar without loading the whole catalog.

## Adding wallpapers

1. Drop images into a folder under `wallpapers/`.
2. Push.
3. The GitHub Action regenerates `thumbnails/`, `images.json` and
   `tags-index.json`.

Apps that already fetch the JSON pick up new files automatically.

## Supported formats

JPG / JPEG, PNG, WebP.
